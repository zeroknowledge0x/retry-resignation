One line, from the retry loop that finally gave up. No clock, no network, no
randomness: the same bytes on every run, as the replay requires.

Run with Node 22: `node --experimental-strip-types main.ts`. The program writes
the single line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
